# IMAN Bootcamp — Frontend Track

## About the Project

This website was created as the final project for the IMAN Bootcamp Frontend Track.

The website introduces the Frontend Track, explains what students will learn, showcases student projects, and provides a contact section.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Responsive website design
* Navigation menu
* Contact form
* Form validation
* Contact form popup
* FAQ accordion
* Project filtering
* Student project showcase

## Project Structure

```text
IMAN-Bootcamp/
│
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
```

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Interact with the website features.
